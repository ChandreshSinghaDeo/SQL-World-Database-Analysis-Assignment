# SQL Aggregation Analysis Assignmnent: World Database

## Project Overview
This project contains a series of SQL queries designed to extract insights from the standard MySQL `world` database. The focus is on using aggregate functions, complex joins, and filtering techniques to answer demographic and economic questions.

## Key Concepts Covered
* **Aggregations:** Using `SUM()`, `AVG()`, `COUNT()`, `MIN()`, and `MAX()`.
* **Filtering:** Distinguishing between `WHERE` (row-level) and `HAVING` (group-level) clauses.
* **Joins:** Linking `country`, `city`, and `countrylanguage` tables to perform cross-table analysis.
* **Sorting & Limiting:** Identifying top performers using `ORDER BY` and `LIMIT`.

## Questions Answered
1. Population trends by continent.
2. Language distribution per region.
3. Economic indicators (GNP) across various geographic scales.
